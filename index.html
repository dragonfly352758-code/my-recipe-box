Cloud sync setup

Sync recipes, notes, favorites, and compressed photos between devices using your own free-tier Supabase project. This requires a one-time setup. Your recipes stay local until you connect and sign in.

One-time setup instructions and database SQL
  1. Create a Supabase project at supabase.com/dashboard.
  2. Open SQL Editor, paste the SQL below and run it.
  3. Under Authentication → Providers, enable email. For hosted apps, set Supabase Authentication → URL Configuration → Site URL to your GitHub Pages URL. Default Magic Link emails will sign you in when opened in the same browser.
  4. Copy the Project URL and public publishable/anon key from the project's API settings into the fields above. Never use a secret/service_role key.
  5. Save connection, request a sign-in code, enter it, then choose Sync now. Repeat on your second device with the same project and email.
create table if not exists public.recipe_box (
  user_id uuid not null references auth.users(id) on delete cascade,
  id text not null,
  recipe jsonb not null,
  updated_at timestamptz not null default now(),
  primary key (user_id, id)
);
alter table public.recipe_box enable row level security;
create policy "Read own recipe box" on public.recipe_box
  for select to authenticated using ((select auth.uid()) = user_id);
create policy "Insert own recipe box" on public.recipe_box
  for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "Update own recipe box" on public.recipe_box
  for update to authenticated using ((select auth.uid()) = user_id)
  with check ((select auth.uid()) = user_id);
